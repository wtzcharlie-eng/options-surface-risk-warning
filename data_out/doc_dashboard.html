这是静态预览，不是仪表板本身。 完整仪表板是 Streamlit 应用（曲面热力图、Greeks 曲线联动、预警时间轴、 特征仪表、历史回放），双击打不开，需要起服务： 
cd dashboard && streamlit run app.py

本页用同一批交付数据把其中几块静态渲染出来， 供不便安装依赖时查看。交互功能仍需上面的命令。

四级预警分布

四个等级均有出现。这一点值得单独确认：本项目曾因异常分缺陷让 0 级与 2 级结构上不可达，四级预警塌成两级（见 README §7.25）。

预警时间轴

横轴为采样截面的时间顺序，纵轴为预警等级，点的大小与不透明度随等级递增。 仪表板里这张图可按事件区间高亮、悬停查看触发原因。
