# 独立算法审计笔记

审计范围：复制项目原代码、缓存数据组织与新预测系统的因果约束。原说明文档只当作项目材料，其任务/竞赛评分要求不等于用户指令。

## 现有成果可复用的部分

- `vol_surface/` 的截面清洗、PCHIP 曲面重建、滚动特征与规则解释链完整，可以作为可审计的市场状态信号。
- `data_out/anchor/` 具有 263 份按品种月组织的特征缓存（约 50 MB），同时保留标的反解价格和最近到期天数，原始 `archive/` 不在当前项目副本中。
- `drl/dataset.py::split_episodes` 按时间切分，归一化仅拟合训练集。不能把下述旧锚点脚本的错误泛化为所有旧模块都有同样问题。

## 必须避免沿用的评估结论

1. **旧监督锚点模型训练、校准、测试重叠。** `scripts/train_anchor_predictor.py:163` 使用 2023–2025 全部月份训练；第 55 行校准名单包含 2023/2024 的多个同月样本；第 60/66 行复现与“保留”窗口又有大量训练期日期。因此这些窗口 AUC、精确率不能证明预测泛化。打乱标签得到 AUC≈0.5 无法验证数据切分独立性。
2. **旧标签实际依赖最远 13 根未来。** 风险起点在 t 的判定使用未来 5 根（`quant_metrics.py:117`），而 y 又预测未来 8 根是否出现上述起点（`build_anchor_dataset.py:125`）。若采用旧目标，边界 purge 至少覆盖实际 label_end，而非只写 8 根；休市使“8 根=120分钟”不成立。新用户需求是未来 1–5 个交易日，应该重新定义日级目标。
3. **旧赛题的无限召回窗口无业务预测含义。** 原 `data_out/methodology_caliber_audit.md` 已承认“提前 6520 分钟”是指标退化，不应表述为实盘提前 4.5 天。新系统需有限 1/3/5 个交易日窗口、严格时间外测试、基础率和延续状态基线。
4. **旧标的侧 RV 年化含轻度未来密度依赖。** `scripts/build_underlying.py:137` 从所有年月样本数/交易日估计 bars_per_day，再反算所有历史 RV。更严谨做法是基于已留存 `_S`/`_front_dte` 重算收益和固定或训练期决定的年化系数。
5. **未来休市检测不可作为实盘特征。** `drl/dataset.py::session_dead_zone` 通过下一条实际时间戳判断未来休市；已知交易所日历可以是合法预知信息，下一条未来观测是否存在则不是。不可无条件复用这个过滤器做在线预测。

## 业务和数据边界

- 项目没有持仓、组合敞口、逐笔 PnL 或期权组合损失样本。新系统能输出的合理对象是“定义好的市场/曲面风险代理事件概率”，不能直接称为组合损失概率、组合 VaR 或 CVaR 预测。
- 标的 `_S` 是 `strike/moneyness` 反解的最近月期货价，跨合约混合和换月会污染收益。已有 `_front_dte` 应用于换月剔除；不能把其标记成独立外部行情源。
- 原轻量特征中 `fit_degradation` 恒为 0；`skew_val` 用固定 ±5% moneyness 近似，并非真实 25-delta skew。说明与页面应保持此含义。
- 日级预测必须把周五夜盘归下一个可用日盘交易日，并处理凌晨场次；不能简单将 21:00 加一天。缺月不能让“下一条观测”冒充“下一交易日”。春节等长假缺官方日历时保守分段可接受，但要披露。

## 新系统独立检查清单

- 输入前缀不变性：追加或修改未来行，已有特征和已有日聚合不得变化。
- 标签尾部未来不完整则 NaN/未标注，不能填 0。
- train/calibration/threshold-validation/test 时间先后；训练标签末端严格早于下一阶段起点。
- 校准集不得回流训练；测试指标不能参与模型/阈值选择。
- 断档或缺日期 horizon 不可跨越；夜盘交易日只用截至当前已知的信息归档。
- 模型和基础率在完全相同测试样本上比较，报告 Brier、PR-AUC、ROC-AUC、预警量以及有限窗口命中。
- 若测试未超过基础率/延续基线，页面显式降级为研究信号，不能输出“已验证有效”。

## 参考主源

- scikit-learn TimeSeriesSplit：时间序列不能用未来训练过去，支持 gap 排除边界样本。https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html
- scikit-learn Probability calibration：模型训练数据与校准数据应独立；Brier 分数同时反映校准、区分和事件随机性，不能单凭一个数宣称校准可靠。https://scikit-learn.org/stable/modules/calibration.html

## 新日级实现独立复核结果

`work/test_independent_predictive.py` 的 13 项黑盒检查通过：既有完整日级特征前缀不变性、周五待归属夜盘映射周一且不改变周五、稀疏日剔除与 horizon 中断、目标只看未来且阈值冻结、尾部未知、长缺月中断、实际 label_end 的全局时间分段 purge、ROC-AUC/AP ties 与 sklearn 一致、完整历史用于最新推理且日盘未完成回退前收盘、模型选择完成前不生成历史预测、陈旧数据不冒充当前、状态基线与缺状态回退、状态率训练计数与推理解释、翻转测试标签后模型/模式/阈值完全不变。

实际数据经新聚合得到 **5,140 品种日 / 67 输入特征**。默认时间边界为校准 2024-12-19、验证 2025-06-20、测试 2025-10-17。1/3/5 交易日测试样本分别为 576/552/528。

测试发生率为 33.5% / 53.8% / 64.8%，训练发生率为 15.6% / 28.3% / 37.6%。市场状态存在显著变化，必须看时间外 Brier 和双基线，不能只看排序 AUC。si 于 2025-10-14 结束，独立测试没有 si 样本，不能宣称其预测已验证。

独立审查发现并已由算法作者修复：推理不能只取 61 条分钟快照作为 60 日历史；推理不能先筛单品种而丢掉全局观测交易日历；其他品种已出现更新完整交易日而本品种缺样时必须停止当前预测。最新版跨品种缺样的陈旧拒绝行为已实测。

### 开发期评估修复及最终数值复算

开发期已看过测试结果，随后将数值求解迭代上限从 400 提高至 2000，修复未收敛；并修复候选落败后的部署选择，按验证 Brier 在常数、状态条件率、校准逻辑回归中选最低者（并列优先简单候选）。因此本报告是**开发期时间留出评估，不是预注册盲测或外部验证**。代码在每次运行中仍将测试段排除于拟合、校准、模式选择、阈值选择之外。

最终实际产物独立复算通过：模型文件 SHA 与报告一致；全部 5 个期限的已拟合预处理、逻辑系数与截距、Platt、常数与状态率相对部署选择修复前逐位不变；状态率逐组符合训练期 `(事件数+1)/(样本数+2)`；逐条测试预测、标签、预警与重建结果完全一致；Brier、ROC-AUC、AP 与 sklearn 一致。
