# V3 分层校准与保守风险率融合：开发期验证

已完成日盘收盘后，联合预测未来1–5个观测交易日内首次未来超阈值的累计概率。ATM隐波或凸性违反代理任一日最大值超过预测日前最近60个完整交易日（至少20日）95%分位即为事件；阈值在预测原点冻结。当前正常与已异常状态分开建模。所有期限共享一条离散时间风险率曲线，累计概率为1−∏(1−风险率)。这是曲面异常代理，不是持仓亏损概率或VaR。观测交易日不是官方交易所日历。

**此前已查看全部历史和 V2 结果；本报告不是外部盲测。所有实验规则在 V3 首次评分前固定，未按测试结果追加候选。**

V3 沿用 V2 的训练候选、因果特征和标签，新增独立校准段的受约束斜率与品种收缩偏置。基准接受完全相同的校准。特征候选只以 25% 或 50% 风险率权重与统计基准融合；每个任务按过去验证段的配对误差改善减十日期块标准误选择，支持不足或改善不足则保留统计基准。完整曲线共用融合权重，不对累计概率排序修饰。统计基准关闭预测预警。

三轮时间窗口、完整五日原点及门禁与 V2 一致。最终模型保持第三轮原样，不以最后测试标签重训。与冻结 V2 逐条原点严格配对；不能把校准基准的改善算作特征模型增量。

## 原始概率与运行口径

Brier/log-loss 评价全部测试原点上的原始校准概率。报告另存固定五档可靠性表、分箱描述性 ECE、平均概率和事件率。ECE 依赖分箱且小样本易波动，不能单独证明校准改善。运行召回保留全部原点，弃权按未预警计入；概率可用率包含统计基准，特征信号覆盖率只包含已选特征融合且通过门禁的原点。

## 边界与复现

- 验证选择的块标准误是预设保守启发式，不是正式显著性检验；候选可能在未来窗口失效。
- 表中 95% 区间来自同日跨品种共同十观测日期块、500 次重采样，条件于已拟合模型，未做多重比较校正。
- 当前为历史曲面代理回放，无实时行情、官方日历、账户持仓或损益；不能称为 VaR/亏损概率。
- persistence 为当前异常后未来窗口至少一次超阈值，不是连续异常时长或恢复时间。
- 历史收盘回放年龄为零，不能检验真实断流、传输延迟；实时调用仍检查数据过期。
- 正标签连续原点片段不等于真实去重事件，不宣称实际事件提前天数。
