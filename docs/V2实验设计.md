# V2 预设实验设计与披露

此设计在 V2 拟合和读取 V2 测试分数前固定。已有全部历史和 V1 留出结果此前已被开发人员查看，因此后续滚动结果统一称为开发期验证，不能称为外部盲测。外部有效性需部署后新增的完整标签验证。

- 固定三轮测试起点：2024-12-19、2025-06-20、2025-10-17。前两轮在下一轮边界前结束，标签到达下一边界的原点剔除。
- 每轮此前所有品种共用的观测日期，前 60% 为训练，60%–80% 为独立概率校准，80%–测试边界为候选和预警阈值选择。每段都按实际第 5 个交易日标签结束时间严格清除越界原点。
- 1–5 日期限统一使用完整 5 日窗口齐全的同一批原点。阈值只从原点以前观测计算，在未来窗口冻结；不使用原项目旧标签。
- 正常原点的新增超阈值与已经异常原点的未来超阈值分开拟合和评价。后一个目标是未来任一日再超阈值，包含异常延续，但不是不中断持续或恢复时间模型。
- 候选固定三个：同品种/当前状态/未来步长条件风险率、固定正则联合风险率、同一模型增加固定 126 观测交易日半衰期权重。复杂模型不做网格搜索；训练、独立校准后，按过去验证段五期限平均 Brier 逐品种/任务选模，并列优先简单候选。支持不足回退基准；无测试驱动的回退。
- 基准和模型均在相同过去校准段校准风险率。风险率通过生存概率连乘转换成累计风险，使累计概率天然单调。分期限预警阈值只在过去验证段按 F1 确定。误报和漏报的实际业务成本尚未提供；此次不根据测试结果追加预算或重调阈值。基准概率作为统计参考不发出增量预测预警。
- 最后一轮原样模型是交互系统最终版本；不再使用其测试结果训练或选择。冻结的 V1 模型只在第三轮且其可用时间之后做相同原点配对比较，前两轮不使用未来生成的模型。
- 原始 Brier/AUC/AP 和运行门禁后的覆盖率、全原点召回、精确率、每观测月误报数分别报告。缺失/严重 OOD/历史不足/不一致弃权保留在运行分母。门禁后概率分数只描述可用子集，不能替代全原点分数。概率可用率包含展示的统计基准曲线；另报 predictive_signal_coverage，要求选中了复杂模型且通过门禁。
- 历史回放以每个完整日盘收盘为时点，数据年龄为零。未模拟实时行情时延和断流；实时服务仍需过期判断。已观察日盘日期不是官方交易所日历。
- 正标签原点连续片段仅是代理预警片段，不是真实事件去重，也不提供真实提前天数。报告逐条标签结束日期，未来有精确事件映射后再做真实事件口径回测。
- Brier 对基准差额和 skill 的 95% 区间用同日跨品种共同的 10 个观测日期循环移动块重采样，固定 500 次、种子 42。重采样不重新拟合模型；区间是开发期探索性统计，不作多重比较校正，不证明未来泛化收益。

每轮、每期限、每任务、每品种指标写入 report.json；test_predictions.csv/Parquet 保留全部测试原点和弃权原因。报告保存原始数据分片、算法源文件、训练脚本和模型的 SHA-256 及运行依赖版本。固定参数记录于模型和报告。
