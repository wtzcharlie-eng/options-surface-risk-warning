# V3：分层校准与保守风险率融合

本设计在读取 V3 实验成绩之前固定（2026-10-23）。V1/V2 的历史与成绩已经查看，故所有历史结果仍属开发验证，不是盲测。V2 源代码、模型、报告、预测产物保持冻结。

## 固定改动

1. 沿用 V2 因果输入、正常/已异常两任务、冻结阈值标签与完整五日窗口；沿用三轮全局时间切分和按实际五日标签末端清除重叠。
2. 保留 V2 三种训练候选及原正则/时间衰减参数。所有候选（包括统计基准）在同一独立校准段拟合 `sigmoid(a + b * 原始风险率logit + 品种偏置)`。`b` 限制在 [0,1]，仅允许压低过度自信；`a` 与品种偏置限制 [-4,4]。全局截距、斜率向 1 的正则系数分别 .01/.05；每品种偏置使用相当于 20 个风险行的二次惩罚。校准不足五个事件/非事件时保留未校准风险率。优化不收敛也回退未校准并记录。
3. 在风险率空间把特征候选向同任务已校准统计基准收缩，特征权重只取 0.25/0.50。五个候选是统计基准、普通模型两种权重、时间衰减模型两种权重；不尝试更多权重。全部未来步骤共用一个权重，再由 `1-∏(1-h)` 生成累计概率，保留结构一致性。
4. 选择单位从小样本的“品种×任务”改为每任务共用一条规则。五期限平均 Brier 为目标；至少 60 个验证原点、五日事件与非事件各至少 10 个、至少四个不重叠十观测日块，才允许特征融合。每个融合相对基准的平均误差改善须超过一倍日期块均值的标准误，选改善减标准误最大的候选，平分优先小权重/普通模型。标准误只是保守选择启发式，不是显著性检验或置信保证。不同品种仍有训练条件风险率和受收缩的校准偏置。
5. 特征融合的预警阈值按同任务全部过去验证原点 F1 选择，避免逐品种小样本选阈值；统计基准关闭预测预警。未追加测试驱动的预警预算。误报/漏报真实成本仍待业务提供。

## 验证与上线口径

- 三轮测试起点沿用 2024-12-19 / 2025-06-20 / 2025-10-17；最后产物保持第三轮原样模型，不以其测试标签重训。
- 与冻结 V2 全三轮逐条预测按轮次、品种、时点、期限严格一对一配对，要求标签和样本全集相同。报告比较 V3、V2 原模型和 V3 更强校准基准，不能把改进基准本身当成特征增量。
- 使用冻结 V2 的相同质量门禁；明确运行召回保留弃权，概率可用率包含统计基准，特征信号覆盖率不包含基准。
- 增加 log-loss、平均预测与事件率、固定五档可靠性表；ECE 仅作分箱描述，不能代替 Brier 或稳定泛化证据。
- 日期块重采样沿用十日期、500 次、种子 42；区间条件于已拟合模型，不重训、未做多重比较校正。已有历史被查看，不能据此宣称实盘有效。
- 本轮不依据 V3 测试分数追加候选或改参数；可修正确性错误并明确记录。界面保留 V1/V2 对照与研究回放标识。

方法参考：[概率校准及独立校准样本](https://scikit-learn.org/stable/modules/calibration.html)、[按时间先后验证](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)、[离散风险率参数化](https://arxiv.org/abs/1910.06724)。品种收缩、融合权重和选择规则为本项目的预设工程设计，文献不保证这些具体设置能改善本项目。
