# 公网分享

分享网址：https://wtzcharlie-eng.github.io/options-surface-risk-warning/

“Publish public HTML”发布流程成功后，收件人可以直接用浏览器打开此网址，无需下载 HTML 或安装项目。网页提供项目介绍、报告、曲面预警展示、知识图谱和历史预测评估。完整 Python 预测服务与真实大模型问答仍按部署说明启动。

公开站点从 index.html 及其链接到的已跟踪资源生成，Markdown 报告转为 HTML 阅读页。真实密钥、根目录 .env 和比赛私有 ZIP 不会发布。

更新网页、报告或公开站点导出脚本并推送至 main 后，GitHub Actions 会重新发布；也可手动运行 Publish public HTML。发布记录见仓库 Actions。

本地生成公开网页：

```sh
python3 scripts/export_public_site.py --source . --out _site
python3 -m http.server 8790 --directory _site
```

生成目录必须为空，以免旧文件混入公开内容。公网展示与比赛平台部署是不同的发布目标，比赛平台提交包和既有验收指纹保持独立。
