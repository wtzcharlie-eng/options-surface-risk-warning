# 旧版 kg 骨架（v1，已归档）

保留作对照，**不参与当前交付**。归档原因：

1. **主推理骨架未经数据检验**：AMPLIFIES 的边权是「启发式 0.6–0.8」的先验；
   跨品种回退权重写死 `1.0`，等于断言「同板块必然传导」。
   `schema_v1.md` 自己也注明「后续可用 anchor 数据估计」——这一步一直没做。
   知识图谱最容易滑向的失败模式就是把作者的断言包装成「推理」，v1 正落在这里。
2. **可移植性**：`build_graph_v1.py` 第 58 行在 f-string 表达式内换行，
   该写法 Python 3.12+ 才合法。在开发机（3.14）上正常，但在 3.10/3.11 环境下是
   SyntaxError。v2 已避免此类写法。
3. **依赖**：v1 依赖 NetworkX，而项目 `requirements.txt` 中并没有它。

v2 保留了 v1 的两个好想法——节点分类体系（ANOM/MECH/CONSEQ/品种/板块），
以及用 anchor 数据实测跨品种共现率（CORRELATES）——但把**主干边改为在 90k 真实截面上
实测 + 分块置换检验 + 训练/测试两段验证**，并去掉了新依赖。

> **注**：`build_graph_v1.py` 含一处跨行 f-string 表达式（PEP 701），在 Python 3.12+ 下合法、
> 在 3.10 下 `python -m compileall` 会报语法错。该文件**从不被导入**，仅作归档留证，
> 不影响任何交付链路；在 3.10 环境下复现时请忽略这一条。
